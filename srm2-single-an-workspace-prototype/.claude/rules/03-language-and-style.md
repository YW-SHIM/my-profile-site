# Rule 03: Language & Labeling Mandate

## Communication Guidelines
- Use clear, straightforward English for all UI labels, tooltips, and prompts.
- Use simple sentences and direct verbs (e.g., `Approve & Send Arrival Notice`, `Verify Code`, `View in OPUS`, `Must check`, `Save`).

## UI Label Standard Mapping
- `CNEE/NTFY` -> `Consignee / Notify Contact`
- `mtch_flg` -> `Match Status`
- `val_cd` -> `Validation Code`
- `Code for A/N` -> `Verified Customer Code`
- Main Action Button -> `Approve & Send Arrival Notice`
