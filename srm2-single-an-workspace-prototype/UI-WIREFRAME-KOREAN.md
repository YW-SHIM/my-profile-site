## 📏 레이아웃 섹션별 상세 설명

### 1️⃣ 상단 필터 바 (TopFilterBar / AdvancedFilterBar)

**위치:** 전체 화면 최상단  
**높이:** 약 180-220px (콘텐츠에 따라 동적)  
**배경:** 마젠타 그래디언트 (`from-pink-600 to-pink-500`)  
**텍스트:** 흰색

#### 1-1) 헤더 영역
```
┌────────────────────────────────────────────────────┐
│ 📦 도착 공지: 통합 워크스페이스                      │  ← 제목 (bold, 18px)
│ 예약 관리 > 선적 개요 > 도착 공지                  │  ← 브레드크럼 (12px, 밝은 핑크)
│                                  [👤] [🔔] [⚙️]  │  ← 우측 메뉴 버튼
└────────────────────────────────────────────────────┘
```

**설명:**
- 왼쪽: 프로젝트 아이콘(📦) + 제목 + 브레드크럼
- 오른쪽: 사용자(👤), 알림(🔔), 설정(⚙️) 버튼
- 알림 버튼에 빨간 점 (미읽 알림 표시)

#### 1-2) 검색 유형 탭
```
┌──────────────┬──────────────┬────────────────────┐
│ VVD + POD    │ ETA + POD    │ 고객코드 + POD     │
└──────────────┴──────────────┴────────────────────┘
 ↓ 현재 활성   ↓ 비활성       ↓ 비활성
 (흰색 배경)   (반투명)       (반투명)
```

**동작:**
- 탭 클릭 시 하단 입력 필드 동적 변경
- 활성 탭: 흰색 배경 + 마젠타 텍스트 + 그림자
- 비활성 탭: 반투명 흰색 배경 + 밝은 핑크 텍스트

#### 1-3) 동적 입력 필드 (VVD + POD 탭 선택 시)
```
┌─────────┬─────────┬──────────┬──────────┐
│   VVD   │   POD   │ [검색]   │ [초기화] │
│ 입력칸  │ 입력칸  │ (흰색)   │ (반투명) │
└─────────┴─────────┴──────────┴──────────┘
```

**필드별 설명:**
- **VVD (선박/항차/방향):** 예) HODT0010E
- **POD (수출지):** 예) Shanghai Port
- **[검색] 버튼:** 흰색 배경, 마젠타 텍스트, 돋보기 아이콘
- **[초기화] 버튼:** 반투명 흰색, 흰색 텍스트

#### 1-4) ETA + POD 탭 선택 시
```
┌────────────┬────────────┬─────────┬──────────┬──────────┐
│ ETA From   │ ETA To     │   POD   │ [검색]   │ [초기화] │
│ 날짜선택   │ 날짜선택   │ 입력칸  │ (흰색)   │ (반투명) │
└────────────┴────────────┴─────────┴──────────┴──────────┘
```

#### 1-5) 고객코드 + POD 탭 선택 시
```
┌──────────────┬─────────┬──────────┬──────────┐
│ 고객코드     │   POD   │ [검색]   │ [초기화] │
│ 입력칸       │ 입력칸  │ (흰색)   │ (반투명) │
└──────────────┴─────────┴──────────┴──────────┘
```

#### 1-6) 빠른 필터 & 고급 옵션
```
┌──────────────┬──────────────┬──────────────┐        ┌──────────┐
│ 📋 전체      │ ⚠️ 매칭 안됨   │ ✓ 발송 준비   │        │ [보기] ▼ │
│ (반투명)     │ (반투명)     │ (반투명)     │        └──────────┘
└──────────────┴──────────────┴──────────────┘        
활성 시: 흰색 배경 + 마젠타 텍스트
```

**테두리:** 마젠타 (top)

#### 구조
```
┌───────────────────────────────────────────────────────────────┐
│                                                               │
│  ┌─────────────────┐  ┌──────────────┐  ┌───────────────┐  │

│  │                 │  │             │  │ 버튼         │  │

│  │ ⚠️ 선택 필요    │  │ (파랑 배지)   │  │ (마젠타,    │  │
```

#### 4-1) 좌측 - 선택 카운터
```
┌──────────────────┐
│  📦 0 / 3        │  ← 선택 / 전체
│                  │
│ ⚠️ 선택 필요    │  ← 경고 메시지 (선택 없을 때)
└──────────────────┘
  └─ 마젠타 왼쪽 테두리
  └─ 흰색 배경
```

**동작:**
- **선택 없음:** "⚠️ 선택 필요" 메시지 표시, 버튼 비활성화
- **1개 이상 선택:** "1 / 3" 형식으로 숫자 업데이트, 버튼 활성화

#### 4-2) 중앙 - 상태 배지
```
┌──────────────────┐
│ 준비 완료        │  ← 상태 텍스트 (파랑)
│ (둥근 모양)      │
└──────────────────┘
  └─ 흰색 배경
  └─ 파랑 텍스트 (text-blue-700)
```

**상태 종류:**
- **준비 완료** - 파랑 배지 (Ready to Send)
- **발송 중...** - 주황 배지 + 펄스 애니메이션 (Sending...)
- **발송 완료** - 초록 배지 (Dispatched)

#### 4-3) 우측 - 주요 액션 버튼

   - 커서: not-allowed
   - 상태: 클릭 불가

   - 커서: pointer
   - 상태: 클릭 가능

   - 배경: 초록색 (`bg-green-500`)
   - 상태 배지: "발송 완료"

## 🔄 사용자 상호작용 플로우

### 1️⃣ 필터링 및 검색
```
1. 검색 유형 탭 클릭 (VVD+POD / ETA+POD / 고객코드+POD)
   ↓
2. 입력 필드에 값 입력
   • VVD + POD: VVD 입력 → POD 입력
   • ETA + POD: 날짜 범위 입력 → POD 입력
   • 고객코드 + POD: 고객코드 입력 → POD 입력
   ↓
3. [검색] 버튼 클릭
   ↓
4. 좌측 패널의 B/L 목록이 필터링됨
   ↓
5. [초기화] 버튼으로 필터 해제 가능
```

### 2️⃣ B/L 선택 및 상세 조회
```
1. 좌측 패널에서 B/L 카드 클릭 또는 체크박스 선택
   ↓
2. 중앙 패널의 상세 정보 업데이트
   • 상단: 선적 상세 정보 (VVD, POD, 배송 조건 등)
   • 하단: 수신자 연락처
   ↓
3. 신뢰도 배지 색상 자동 표시
   • 초록(95%↑): Matched
   • 파랑(80-95%): AI_Suggested  
   • 주황(<80%): Unmatched
   ↓
4. 비고 필드에서 추가 정보 입력 가능
```

### 3️⃣ 배치 선택 및 승인
```
1. 여러 B/L 선택
   • 개별 체크박스 또는 "☑️ 전체 선택"
   ↓
2. 하단 바의 카운터 업데이트
   • 예: "2 / 3"
   ↓
3. 상태 배지 업데이트
   • "준비 완료" (파랑)
   ↓
4. 주요 액션 버튼 활성화
   • 배경이 마젠타로 변경
   • 커서가 pointer로 변경
   ↓
5. [✓ 도착 공지 승인 & 일괄 발송] 버튼 클릭
   ↓
6. 발송 프로세스 시작
   • 버튼 상태: "발송 중..." (주황, 펄스 애니메이션)
   • 예상 소요 시간: 2-5초
   ↓
7. 발송 완료
   • 상태 배지: "발송 완료" (초록)
   • 성공 메시지 표시
   • 3개 BL의 도착 공지가 각 수신자에게 발송됨
```
