## 🔄 사용자 플로우 (4단계)

### Step 1️⃣ 검색
```
검색 탭 선택 
  ↓
입력 값 입력 (VVD, POD 또는 날짜, 고객코드 등)
  ↓
[검색] 버튼 클릭
  ↓
좌측 패널 B/L 목록 필터링
```

### Step 2️⃣ 선택
```
B/L 체크박스 선택 (또는 "☑️ 전체 선택")
  ↓
하단 카운터 업데이트: "1 / 3"
  ↓
주요 버튼 활성화: 회색 → 마젠타
```

### Step 3️⃣ 검증
```
B/L 클릭 → 중앙 패널 상세 정보 표시
  ↓
신뢰도 배지 확인:
  • ✅ 98% (초록) = 완벽 일치
  • 🤖 87% (파랑) = AI 제안
  • ⚠️ 65% (주황) = 매칭 필요
  ↓
필요시 비고 필드 수정
```

### Step 4️⃣ 승인 & 발송
```
[✓ 도착 공지 승인 & 일괄 발송] 버튼 클릭
  ↓
상태 변화:
  1. "발송 중..." (주황) + 펄스
  2. 예상 소요: 2-5초
  3. "발송 완료" (초록) + 성공 메시지
  ↓
3개 BL의 도착 공지가 수신자에게 발송됨
```
